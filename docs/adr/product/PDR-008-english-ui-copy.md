# PDR-008: English UI copy and documentation

- **Status:** Accepted
- **Date:** 2026-10-10

## Context

The hackathon jury is international. The team is French-speaking, and Swissquote's market is multilingual (FR/DE/IT/EN).

## Decision

The UI copy, README and ADRs are written in **English**.

## Consequences

- ✅ Judges can read everything.
- Localization (FR/DE/IT) is possible later. Copy is currently inline in the components, so it would need extracting first.
